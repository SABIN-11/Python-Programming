# Python Programming

A collection of my Python programming practice, problem-solving exercises, and small projects as I build my programming fundamentals and prepare for more advanced work in computer science and AI/ML.

## Repository Structure

- `python_restart/` — Core Python fundamentals and refreshed practice.
- `built_in_data_structures/` — Practice with Python's built-in data structures and related operations.
- `stringMethods/` — Practice with Python string methods and manipulation.
- `special_functions/` — Practice with special and commonly used Python functions.
- `bitwiseProblems/` — Bitwise operations and problem-solving exercises.
- `patternProblems/` — Pattern-based programming exercises.
- `recursion/` — Recursive problem-solving exercises.
- `sorting_algorithms/` — Implementations and practice involving sorting algorithms.
- `OOPS/` — Object-oriented programming concepts and exercises.
- `Pygame/` — Programs and experiments using Pygame.
- `projects/` — Small Python programs and projects.
- `practice/` — General Python practice.
